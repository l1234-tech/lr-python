## Темы и технологии

- **Python:** функции, алгоритмы, рекурсия, структуры данных.
- **Тестирование:** модульные и интеграционные тесты.
- **Производительность:** `timeit`, сравнение реализаций, асинхронность и multiprocessing.
- **Cython:** компиляция горячих участков вычислений.
- **Веб-разработка:** модели, контроллеры, шаблоны и тестирование приложения.
- **Data analysis:** NumPy, Pandas, Matplotlib и Seaborn.

## Как запускать работы

Рекомендуется использовать Python 3 и отдельное виртуальное окружение.

```bash
python -m venv .venv
```

Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

Linux / macOS:

```bash
source .venv/bin/activate
```

Зависимости отличаются между лабораторными. Для работ с NumPy, Pandas и визуализацией могут понадобиться соответствующие пакеты; для LR10 дополнительно используются процессы и расширение Cython. Перед запуском читай README конкретной работы и импорты в исходниках.

## Тестирование

В репозитории есть тесты на базе `unittest` и другие тестовые сценарии. Пример запуска тестов в директории конкретной работы:

```bash
python -m unittest
```

Для тестов, зависящих от текущей директории или внешних расширений, запускай команду из соответствующей папки и проверь необходимые зависимости.

## Авторство и учебное назначение

Репозиторий систематизирует учебные работы и материалы курса. Он помогает повторить решения и изучить применённые технологии; наличие тестов в папке не означает, что каждый тестовый сценарий уже запускался в чистом окружении и успешно прошёл.
