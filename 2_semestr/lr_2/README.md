# Второй семестр — LR2: NumPy и анализ данных

Лабораторная работа объединяет операции с массивами и матрицами, линейную алгебру, статистические показатели, чтение CSV и визуализацию.

## Содержимое

- [`main.py`](./main.py) — набор функций для обработки данных.
- [`test_main.py`](./test_main.py) — тесты функций.
- [`data/students_scores.csv`](./data/students_scores.csv) — набор данных с результатами.
- [`plots/`](./plots/) — сохранённые изображения графиков.

## Темы

1. Создание массивов NumPy и изменение формы.
2. Сложение и умножение векторов.
3. Матричное умножение, определитель и обратная матрица.
4. Решение систем линейных уравнений.
5. Статистический анализ данных.
6. Визуализация с Matplotlib и Seaborn.

## Установка зависимостей

В активированном виртуальном окружении:

```bash
python -m pip install numpy pandas matplotlib seaborn
```

## Запуск и тесты

Запускай команды из этой директории:

```bash
python main.py
python -m unittest -v
```

Некоторые функции и тесты строят графики. Для автоматического запуска в среде без дисплея может потребоваться выбрать неинтерактивный backend Matplotlib.

## Интерпретация

Обрати внимание на форму массивов, совместимость размерностей при матричных операциях и обработку вырожденных матриц. При тестировании визуализации полезно проверять не только отсутствие исключения, но и корректность данных, которые передаются на график.
