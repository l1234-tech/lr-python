## Как поддерживать синхронизацию

- Сайт использовать для демонстрации и удобного просмотра работ.
- В репозитории хранить исходный код, тесты, данные и инструкции по запуску.
- Для каждой новой лабораторной создавать отдельную директорию с README.
- В README указывать ссылку на страницу сайта, если для работы опубликована отдельная страница.

> Примечание: содержимое сайта и исходный код не следует считать автоматически синхронизированными. Когда добавляешь новые работы на сайт, добавляй соответствующие исходники и описание в этот репозиторий отдельно.
