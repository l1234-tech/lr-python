# LR2 — Бинарный поиск

**Тема:** поиск элемента в упорядоченном диапазоне и игра «угадай число».

## Файлы

- [`lr2.py`](./lr2.py) — ввод данных и вызов алгоритма.
- [`guess_number.py`](./guess_number.py) — реализация бинарного поиска.
- [`test_binary_search.py`](./test_binary_search.py) — тесты.

## Что изучается

- Предпосылка бинарного поиска: данные должны быть упорядочены.
- Деление диапазона поиска на части.
- Граничные значения и случай отсутствия элемента.
- Проверка алгоритма тестами.

## Запуск

```bash
python lr2.py
python -m unittest -v
```

Для бинарного поиска на отсортированном массиве типичная временная сложность — (O(\log n)), дополнительная память зависит от конкретной реализации.
