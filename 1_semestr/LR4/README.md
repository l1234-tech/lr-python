# LR4 — Бенчмарки алгоритмов

**Тема:** измерение времени выполнения и сравнение реализаций.

## Файлы

- [`lr4_one_number_benchmark.py`](./lr4_one_number_benchmark.py) — сравнение рекурсивного и итеративного факториала.
- [`lr4_sr_znach_benchmark.py`](./lr4_sr_znach_benchmark.py) — второй эксперимент с измерением производительности.
- [`results_pics/`](./results_pics/) — сохранённые результаты/изображения.

## Что изучается

- Измерение времени через `timeit`.
- Различие рекурсивного и итеративного подхода.
- Визуализация результатов с Matplotlib.
- Влияние размера входных данных на время выполнения.

## Запуск

```bash
python lr4_one_number_benchmark.py
```

Зависимости: `matplotlib`. Бенчмарки лучше повторять несколько раз на одной машине и сравнивать результаты с осторожностью: влияют версия Python, нагрузка процессора и среда запуска.
