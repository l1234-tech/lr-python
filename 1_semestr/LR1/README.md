# LR1 — Two Sum

**Тема:** поиск двух элементов массива, сумма которых равна заданному значению.

## Файлы

- [`lr1.py`](./lr1.py) — реализация `two_sum`.
- [`test_two_sum.py`](./test_two_sum.py) — тесты функции.

## Что изучается

- Перебор пар элементов.
- Индексация последовательностей.
- Проверка входных данных.
- Организация модульных тестов.

## Запуск

Из этой папки:

```bash
python lr1.py
python -m unittest -v
```

Текущая реализация перебирает пары вложенными циклами, поэтому её временная сложность в общем случае квадратичная — (O(n^2)). Перед использованием стоит проверить формат ошибок и граничные случаи по исходному условию.
