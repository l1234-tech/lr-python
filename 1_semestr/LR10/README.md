# LR10 — Численное интегрирование и параллельное выполнение

**Тема:** вычисление интеграла и сравнение разных способов выполнения вычислений в Python.

## Что изучается

- Численное приближение определённого интеграла.
- Разделение работы на задачи.
- Различия между async-подходом и параллельными процессами.
- Вызов скомпилированного расширения Cython.
- Измерение времени выполнения и сравнение результатов.

## Запуск

Сначала проверь и установи необходимые зависимости для используемых библиотек и собери расширение Cython по инструкции в [`cython_integrate/setup.py`](./cython_integrate/setup.py).

Затем из этой папки:

```bash
python main.py
python -m unittest -v
```

Сборка Cython может зависеть от операционной системы, компилятора C и версии Python. Большой benchmark в `main.py` выполняет вычисления с миллионами итераций и может занимать заметное время.

## Как интерпретировать результаты

Сравнивай не только время, но и точность результата. Учитывай накладные расходы на запуск процессов и передачу данных: параллельный вариант не обязан быть быстрее на коротких задачах.
