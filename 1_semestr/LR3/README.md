# LR3 — Рекурсивная генерация дерева

**Тема:** построение древовидной структуры рекурсивно.

## Файлы

- [`lr3.py`](./lr3.py) — реализация `gen_bin_tree`.
- [`test_gen_bin_tree.py`](./test_gen_bin_tree.py) — тестовые сценарии.
- [`readme`](./readme) — исходная заметка лабораторной.

## Что изучается

- Базовый случай рекурсии.
- Рекурсивный переход для левого и правого потомка.
- Представление дерева вложенными словарями и множествами.
- Проверка допустимости входных параметров.

## Запуск

```bash
python lr3.py
python -m unittest -v
```

В текущем скрипте пример выводится при запуске файла. Для использования функции как библиотеки в дальнейшем можно отделить демонстрационный запуск от вычислений.
