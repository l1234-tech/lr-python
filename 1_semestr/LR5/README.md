# LR5 — Итеративная генерация дерева

**Тема:** построение структуры дерева без рекурсивных вызовов.

## Файлы

- [`lr5_not_recursion.py`](./lr5_not_recursion.py) — итеративный алгоритм построения дерева.
- [`test_lr5.py`](./test_lr5.py) — тесты.

## Что изучается

- Замена рекурсии циклом.
- Хранение текущего уровня дерева.
- Преобразование линейного представления в вложенную структуру.
- Проверка недопустимых параметров и граничных значений.

## Запуск

```bash
python lr5_not_recursion.py
python -m unittest -v
```

Сравнивая LR3 и LR5, обрати внимание на то, как отличается управление состоянием рекурсивного алгоритма и итеративного решения.
