# MYAPP — Веб-приложение на Python

Раздел содержит приложение с разделением на контроллеры, модели и HTML-шаблоны, а также набор тестов.

## Структура

| Каталог / файл | Назначение |
|---|---|
| [`myapp.py`](./myapp.py) | Точка запуска и конфигурация приложения |
| [`controllers/`](./controllers/) | Обработка запросов и логика маршрутов |
| [`models/`](./models/) | Модели предметной области и обработка данных |
| [`templates/`](./templates/) | HTML-шаблоны страниц |
| [`tests/`](./tests/) | Модульные и интеграционные тесты |
| [Исходная заметка](./readme) | Первоначальная заметка к лабораторной |

## Возможности по структуре кода

- Работа с пользователями и страницами.
- Контроллеры валют и базы данных.
- Модели пользователя, автора и валюты.
- HTML-шаблоны для страниц, профилей и отчётов.
- Тесты контроллеров, моделей и интеграционных сценариев.

## Запуск

Проверь импорты в `myapp.py` и установи зависимости, которые использует приложение. После настройки локального окружения запускай:

```bash
python myapp.py
```

Точный список библиотек и конфигурационных параметров стоит закрепить в `requirements.txt` или `pyproject.toml`. Не публикуй реальные пароли и ключи подключения, если они используются приложением.

## Тесты

Из директории `MYAPP` можно попробовать:

```bash
python -m unittest discover -s tests -v
```

Интеграционные тесты могут требовать настроенную базу данных или дополнительные переменные окружения — проверь их предусловия перед запуском.
